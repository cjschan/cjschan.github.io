Problem 1 [2 pts]

A college tests \(H_0: p = 0.70\) vs. \(H_a: p > 0.70\), where \(p\) is the pass rate of students in a new tutoring program (the old pass rate was 70%). (1 pt each)

  1. Describe a Type I error in this context.
  2. Describe a Type II error in this context.

(a) Concluding the program raises the pass rate above 70% when it really does not.

(b) Failing to conclude the program raises the pass rate when it really does.

Problem 2 [2 pts]

(1 pt each)

  1. A researcher tests 40 different foods to see whether each is associated with migraines, using \(\alpha = 0.05\) for each test. Even if no food is truly associated with migraines, about how many tests would you expect to be significant? Why is this a problem?
  2. A study of 50,000 people finds that a new app increases average daily steps by 12 steps (p-value = 0.002). Is this result statistically significant? Is it practically significant? Explain.

(a) About \(0.05 \times 40 = 2\) tests would be significant just by chance. Testing many hypotheses makes false positives (Type I errors) likely, so a few significant results could be flukes.

(b) Statistically significant (0.002 < 0.05), but 12 extra steps a day is too small to matter in practice; the huge sample makes even tiny effects significant.

(c) The normal p-value should be similar to the randomization p-value (often a little smaller, because \(\hat{p}\) can only take values \(x/n\) in the randomization distribution); the normal distribution approximates the randomization distribution well for these sample sizes. (d) A 95% CI that excludes 0.5 goes with rejecting \(H_0\) at \(\alpha = 0.05\), and one that contains 0.5 goes with not rejecting. When the p-value is near 0.05 the two can disagree slightly because they are built from different simulations. (e) If the student rejects \(H_0\), a Type I error is possible; if not, a Type II error is possible.
