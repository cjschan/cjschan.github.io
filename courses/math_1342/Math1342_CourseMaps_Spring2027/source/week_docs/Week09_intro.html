Introduction

Welcome back from Spring Break! This week starts hypothesis testing. In 4.1 you will define the parameter and write the null and alternative hypotheses. In 4.2 we build a randomization distribution, assuming H₀ is true, and measure the evidence with a p-value. Hypotheses are always about population parameters (p, μ), never about sample statistics (p̂, x̄).

This week covers: 4.1 Introducing Hypothesis Tests; 4.2 Measuring Evidence with P-Values.

Objectives

  • MLO 1: Identify the parameter of interest in a research question. (CLO 8)

  • MLO 3: Classify a test as right-tailed, left-tailed, or two-tailed. (CLO 8)
  • MLO 4: Explain the logic of a hypothesis test: assume H₀ is true and ask whether the sample data are surprising. (CLO 8)
