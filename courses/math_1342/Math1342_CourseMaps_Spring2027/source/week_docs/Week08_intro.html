Introduction

Last week we needed many samples to see a sampling distribution. This week the bootstrap lets us estimate one from a single sample. In 3.3 you will build a bootstrap distribution in StatKey and use its standard error for a 95% interval. In 3.4 you will use percentiles for 90%, 95% and 99% intervals. A bootstrap can't fix a biased sample. Spring Break follows this week.

This week covers: 3.3 Constructing Bootstrap Confidence Intervals Using Standard Error; 3.4 Bootstrap Confidence Intervals Using Percentiles.
