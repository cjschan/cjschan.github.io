Introduction

This is where inference begins. In 3.1 you will see that a statistic changes from sample to sample, and that the sampling distribution and its standard error measure that variability. In 3.2 we use the standard error to build a confidence interval and interpret it correctly. The most common mistake: a 95% CI does not mean there is a 95% chance the parameter is in this particular interval. The 95% describes the method.

This week covers: 3.1 Sampling Distributions; 3.2 Understanding and Interpreting Confidence Intervals.
