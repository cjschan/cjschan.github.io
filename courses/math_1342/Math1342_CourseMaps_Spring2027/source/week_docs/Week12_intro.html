Introduction

We now apply formulas to specific parameters, starting with proportions. In 6.1 you will check conditions, build a CI and run a z test for one proportion. In 6.3 we compare two proportions with a pooled test and a CI for p₁ − p₂. Note that the CI's standard error uses p̂, while the test uses the null value p₀ (or the pooled p̂). Take-Home Quiz 5 is due Monday.

This week covers: 6.1 Inference for a Proportion (Distribution, CI, Hypothesis Test); 6.3 Inference for a Difference in Proportions (Distribution, CI, Hypothesis Test).
