Introduction

This week moves from proportions to means. In 6.2 you will use the t distribution (df = n − 1) for a confidence interval and a test about one mean. In 6.4 we compare two independent means. The order of the groups sets the sign of the difference, so define it clearly and keep it consistent from the hypotheses to the conclusion.

This week covers: 6.2 Inference for a Mean (Distribution, CI, Hypothesis Test); 6.4 Inference for a Difference in Means (Distribution, CI, Hypothesis Test).
