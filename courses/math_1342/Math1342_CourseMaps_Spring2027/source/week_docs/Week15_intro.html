Introduction

This is the last week of new material. In 8.1, ANOVA compares the means of three or more groups using an F statistic, the ratio of variability between groups to variability within groups. In 9.1 we return to regression and test whether the slope (or correlation) in the population is really different from zero. A significant ANOVA tells you that some means differ, not which ones.

This week covers: 8.1 Analysis of Variance; 9.1 Inference for Slope and Correlation.
