Making Connections

Connecting randomization distributions, bootstrap distributions, confidence intervals, and hypothesis tests.

Generating Randomization Samples

Three criteria for creating samples under the null hypothesis.

1
Be consistent with the null hypothesis.
2
Use the data in the original sample.
3
Reflect the way the original data were collected.

Methods Vary by Situation

The specific simulation method depends on the study design.

Randomized Experiment

  • Re-randomize cases to treatment groups, keeping response values fixed.
  • Example: cocaine addiction study.

Observational Study

  • Shift data to make \(H_0\) true, then bootstrap.
  • Example: body temperature (shift all values so the mean equals 98.6).
For a single proportion, simulate coin flips. The general idea is always the same: simulate what would happen by random chance if \(H_0\) were true.
Two Populations

Two Ways to Simulate \(H_0\) for Two Groups

To test \(H_0: \mu_1 = \mu_2\) (or \(p_1 = p_2\)), we need samples where the group label makes no difference. There are two common ways to make them.

Method 1

Reallocation (re-randomization)

  • Pool all the values, then shuffle and deal them back into two groups of the original sizes.
  • Sampling without replacement: every value is used exactly once.
  • Mirrors the random assignment in a randomized experiment.
Method 2

Resampling (bootstrapping)

  • Pool all the values, then draw at random to fill two groups of the original sizes.
  • Sampling with replacement: some values repeat, others are left out.
  • Mirrors random sampling from two populations in an observational study.
Either way, compute the difference in sample statistics for the new groups, repeat thousands of times, and you get a randomization distribution centered at 0, the null value.
Method 1

Reallocation: Shuffle the Group Labels

A small illustration: 5 treatment and 5 control values. Observed difference \(\bar{x}_T - \bar{x}_C = 17.6 - 13.6 = 4.0\).

Reallocation asks: if the treatment had no effect, how different could the groups look just from which subjects happened to be assigned where?
Method 2

Resampling: Bootstrap from the Pooled Sample

Same data. Now each new group is drawn with replacement from the pool of all 10 values.

Resampling asks: if both samples came from the same population, how different could two random samples look just by chance?

Both distributions are centered at 0 and have similar spread, so they give similar p-values. Choose the method that matches how the data were collected: reallocate for a randomized experiment, resample for random samples from two populations.

Bootstrap vs. Randomization Distributions

They look similar but serve different purposes.

Bootstrap Distribution

  • Does not assume \(H_0\) is true.
  • Centered around the sample statistic.
  • Used for confidence intervals.

Randomization Distribution

  • Assumes \(H_0\) is true.
  • Centered around the null value.
  • Used for hypothesis tests.
The two distributions have the same shape and spread. The only difference is the center.

Confidence Intervals and Hypothesis Tests

A confidence interval and a two-sided test give consistent conclusions.

The Connection

  • If the null value is outside a 95% CI, a two-tailed test at \(\alpha = 0.05\) will reject \(H_0\).
  • If the null value is inside a 95% CI, a two-tailed test at \(\alpha = 0.05\) will not reject \(H_0\).

When to Use Which

  • Confidence intervals: when you want to estimate a parameter.
  • Hypothesis tests: when you want to test a claim about a parameter.

Example: Body Temperature

Using a sample of healthy adults, a 95% confidence interval for the mean body temperature is \((98.05,\ 98.47)\) degrees Fahrenheit. Use the interval to draw test conclusions — no new calculations needed.

Part (a)

Test \(H_0: \mu = 98.6\) vs \(H_a: \mu \neq 98.6\) at \(\alpha = 0.05\)

Is the null value 98.6 inside the interval \((98.05,\ 98.47)\)?

No — 98.6 is outside the interval, so 98.6 is not a plausible value for \(\mu\). We reject \(H_0\): there is sufficient evidence that the mean body temperature differs from the traditional 98.6°F.

Part (b)

Test \(H_0: \mu = 98.4\) vs \(H_a: \mu \neq 98.4\) at \(\alpha = 0.05\)

Is the null value 98.4 inside the interval \((98.05,\ 98.47)\)?

Yes — 98.4 is inside the interval, so 98.4 is a plausible value for \(\mu\). We do not reject \(H_0\): there is not sufficient evidence that the mean body temperature differs from 98.4°F.

The rule: a 95% confidence interval contains exactly the null values that a two-tailed test at \(\alpha = 0.05\) would not reject.

Example: Where Is Each Distribution Centered?

In a sample of 50 students, 28 say they get at least 7 hours of sleep, so \(\hat{p} = 28/50 = 0.56\). We want to test \(H_0: p = 0.5\) vs \(H_a: p \neq 0.5\).

Part (a)

One randomization sample

Simulate what happens if \(H_0\) is true: flip a fair coin 50 times (each flip has probability 0.5 of "yes") and record the proportion of heads. Repeat many times to build the randomization distribution.

Part (b)

Center of the randomization distribution

\(p_0 = 0.5\)

It assumes \(H_0\) is true, so it centers on the null value.

Part (c)

Center of the bootstrap distribution

\(\hat{p} = 0.56\)

It makes no assumption about \(H_0\), so it centers on the sample statistic.

Same data, same shape, same spread — the only difference between the two distributions is where they are centered. The next slide shows both.

What to Remember

Everything connects.

Randomization Samples

  • Consistent with \(H_0\)
  • Use observed data
  • Reflect data collection method

CI and Test Agreement

  • Null value outside 95% CI \(\Rightarrow\) reject \(H_0\) at \(\alpha = 0.05\)
  • Null value inside 95% CI \(\Rightarrow\) do not reject \(H_0\)
