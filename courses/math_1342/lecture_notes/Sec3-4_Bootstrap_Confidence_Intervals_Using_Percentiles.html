Section 3.4

Bootstrap Confidence Intervals
Using Percentiles

A flexible method for any confidence level — just keep the middle P%

Review

What Is Statistical Inference?

Statistical inference is the process of using data from a sample to understand the whole population.

The Goal: Estimate a Parameter

  • A parameter is a number that describes the population
  • It is a fixed value, but it is usually unknown
  • We can rarely measure the entire population, so we estimate it instead

The Tool: Use the Sample

  • A statistic is a number computed from the sample
  • We know its value because we have the sample data
  • A statistic used to estimate a parameter is a point estimate
The big picture: Population \(\rightarrow\) parameter (unknown).   Sample \(\rightarrow\) statistic (known) \(\rightarrow\) used to estimate the parameter.
Review

Parameters and Statistics: Notation

Each parameter has a matching statistic that serves as its point estimate.

Parameters (Population)

QuantitySymbol

Difference in means\(\mu_1 - \mu_2\)
Proportion\(p\)
Difference in proportions\(p_1 - p_2\)
Correlation\(\rho\)
Standard deviation\(\sigma\)

Statistics (Sample)

QuantitySymbol
Mean\(\bar{x}\)
Difference in means\(\bar{x}_1 - \bar{x}_2\)
Proportion\(\hat{p}\)
Difference in proportions\(\hat{p}_1 - \hat{p}_2\)

Read across the rows: each statistic on the right is the point estimate for the parameter on the left, e.g. \(\bar{x}\) estimates \(\mu\) and \(\hat{p}\) estimates \(p\).
Review

From Point Estimate to Interval Estimate

A point estimate will almost never equal the parameter exactly, so we give a range of plausible values instead.

The Form of an Interval Estimate

\[\text{Statistic} \pm \text{Margin of Error (ME)}\]
  • The statistic is the center of the interval (our point estimate)
  • The margin of error reflects how far the statistic is likely to be from the parameter
  • A confidence interval is an interval estimate with a stated confidence level
Recall (Section 3.3): For a 95% CI, \(\text{ME} = 2 \times \text{SE}\), so the interval is \(\text{Statistic} \pm 2 \times \text{SE}\).
Motivation

Beyond 95% Confidence

What if we want a 90% CI or a 99% CI? The SE method used "2" specifically for 95%.

Recall: SE Method (Section 3.3)

\[\text{95% CI} = \text{Statistic} \pm 2 \times \text{SE}\]

The multiplier "2" works specifically for 95% confidence with a bell-shaped distribution.

What multiplier do we use for 90%? 99%? Other levels?

A More General Approach

  • Instead of a formula with a multiplier, we can read the CI directly from the bootstrap distribution
  • This is the percentile method
  • It works for any confidence level
  • No need to remember different multipliers
Method

The Percentile Method

For a P% confidence interval, keep the middle P% of bootstrap statistics.

The Rule

For a P% CI: cut off \(\frac{100 - P}{2}\)% from each tail of the bootstrap distribution

Common Confidence Levels

Confidence Level Cut from Each Tail Lower Percentile Upper Percentile
90% 5% 5th percentile 95th percentile
95% 2.5% 2.5th percentile 97.5th percentile
99% 0.5% 0.5th percentile 99.5th percentile
Example: For a 95% CI, find the 2.5th and 97.5th percentiles of your bootstrap distribution. Those are your lower and upper bounds.
Worked Example

Example: Percentile CIs for Atlanta Commutes

A random sample of \(n = 500\) Atlanta commuters has mean one-way commute time \(\bar{x} = 29.11\) minutes. Find a 90% and a 99% CI for the mean commute time \(\mu\) of all Atlanta commuters.

In StatKey

  • 1. Go to lock5stat.com/StatKey; under Bootstrap Confidence Intervals, choose CI for Single Mean, Median, St.Dev. (Atlanta Commutes is the default dataset)
  • 2. Click Generate 1000 Samples
  • 3. Check Two-Tail. StatKey shades the middle 0.95 and labels the two cutoffs.
  • 4. Click the 0.95 box and change it to 0.90; the cutoffs are the 5th and 95th percentiles
  • 5. Change it to 0.99; the cutoffs are the 0.5th and 99.5th percentiles

Results

One run of 1000 bootstrap means gave about:

90% CI \(\approx (27.6,\; 30.6)\) minutes
99% CI \(\approx (26.7,\; 31.5)\) minutes

“We are 90% confident that the mean commute time for all Atlanta commuters is between about 27.6 and 30.6 minutes.”

The 99% interval is wider (about 4.8 minutes vs. 3.0) because it keeps more of the bootstrap distribution. Your endpoints will differ slightly from run to run.

Relationship

What Affects Interval Width?

How do the confidence level and the sample size affect the interval?

90% CI

Narrow

Keep middle 90%. Cut 5% from each tail. Less confident, but more precise.

95% CI

Medium

Keep middle 95%. Cut 2.5% from each tail. The standard choice.

99% CI

Wide

Keep middle 99%. Cut 0.5% from each tail. Very confident, but less precise.

Smaller Sample Size

  • More variability in the statistic; larger SE
  • Bootstrap distribution is more spread out
  • Results in a wider confidence interval

Larger Sample Size

  • Less variability in the statistic; smaller SE
  • Bootstrap distribution is more concentrated
  • Results in a narrower confidence interval
The trade-off: Higher confidence level \(\Rightarrow\) wider interval (to be more confident we capture the parameter, we cast a wider net). Larger sample size \(\Rightarrow\) narrower interval.

Comparison

Two Methods for Bootstrap CIs

SE method vs. percentile method — when to use which?

SE Method

\[\text{Statistic} \pm 2 \times \text{SE}_{\text{bootstrap}}\]
  • Uses a multiplier (2 for 95%)
  • Assumes the bootstrap distribution is bell-shaped and symmetric
  • Works well for 95% confidence
  • Less flexible for other confidence levels

Percentile Method

Keep the middle P% of bootstrap statistics
  • Read bounds directly from the bootstrap distribution
  • Works for any confidence level
  • Does not require a symmetric distribution
  • More flexible and widely applicable
When they agree: For a symmetric, bell-shaped bootstrap distribution at the 95% level, both methods give very similar results. For non-bell-shaped distributions or non-95% levels, use the percentile method.
Cautions

Bootstrap Cautions

The bootstrap is powerful, but it has limitations.

When to Be Careful

  • The bootstrap distribution should look smooth and roughly symmetric (bell-shaped)
  • If the bootstrap distribution is very skewed or has gaps, the CI may not be reliable
  • Very small samples may not produce trustworthy bootstrap distributions

Other Considerations

  • The original sample must be representative of the population
  • Bootstrapping cannot fix a biased sample
  • Use enough bootstrap samples (at least 1000, ideally more)
  • Always plot the bootstrap distribution to check its shape
Bottom line: The bootstrap works well when the bootstrap distribution is smooth and symmetric. Always visualize it before trusting the results.

The Percentile Method Visualized

1000 bootstrap means with the 0.5th and 99.5th percentiles marked. The middle 99% gives the 99% CI.

The whole distribution is 100%. The lower bound (0.5th percentile) is greater than 0.5% of the bootstrap statistics, and the upper bound (99.5th percentile) is greater than 99.5% of them. That leaves 0.5% in each tail and 99% in between: \(0.5\% + 99\% + 0.5\% = 100\%\).
Recap

Section 3.4 Summary

Percentile Method

  • For a P% CI, keep the middle P% of bootstrap statistics
  • 95% CI: 2.5th to 97.5th percentile
  • 99% CI: 0.5th to 99.5th percentile
  • Works for any confidence level

Key Relationships

  • Higher confidence \(\Rightarrow\) wider interval
  • Larger sample \(\Rightarrow\) narrower interval
  • SE and percentile methods agree when bootstrap distribution is bell-shaped (at 95%)
  • Use percentile method for non-95% levels or non-symmetric distributions

Bootstrap Cautions

  • Only trust bootstrap CIs when the bootstrap distribution is smooth and roughly symmetric
  • Always plot the bootstrap distribution to check
  • The bootstrap cannot fix a biased or unrepresentative sample
